## 2.1 Le pipeline, étape par étape (`idol/pipeline.py`, idol-sdk `8db7003`)

| # | Étape | Entrée → sortie | Référence | Cible Swift |
|---|---|---|---|---|
| 1 | Prétraitement | image quelconque → RGB 1024² sur fond noir | `preprocess.py` | `IdolCore/Preprocess/` |
| 2 | Détourage | RGB (côté court 1024) → alpha | `models/birefnet.py` (Swin-L + ASPP déformable) | `IdolCore/Models/BiRefNet/`, derrière `BackgroundRemover` |
| 3 | Conditionnement | pixels [1,3,1024,1024] ∈ [0,1] → `feature1` [1,4101,1280], `feature2` [1,4101,128] | `conditioning.py` | `IdolCore/Models/Encoders/` |
| 4 | Débruitage | bruit `latent` [1,8192,16] + `camera` [1,1,5] → échantillon | `sampler.py`, `models/dit.py` | `Models/Denoiser/`, `Sampling/` |
| 5 | Ancrages | latent → `num_gaussians/32` points ∈ [0,1]³ | `decoder.py` `OctreeProbabilityFixedlenDecoder.sample` | `Decoding/` (CPU) + `Models/Decoders/` |
| 6 | Gaussiennes | ancrages + latent → 32 × 15 sorties brutes par ancrage | `GaussianFixedlenDecoder` | `Models/Decoders/` |
| 7 | Sortie | activations, `.ply`, caméra | `gaussian.py`, `camera.py` | `Output/` (fait, T-1.0) |

### Faits d'orchestration (ne pas re-dériver)

- **Graine unique** : `torch.manual_seed(seed)` *avant* l'encodeur ; l'échantillon du VAE
  (`latent_dist.sample()`) consomme donc le flux avant le bruit du débruiteur. En Swift, chaque
  tirage passe par `NoiseSource` ; la parité rejoue les tirages Python (`plan/10-tests.md`).
- **Ordre des tirages** : VAE posterior → `latent` → `camera` → par niveau d'octree, les offsets
  systématiques → jitter final des ancrages. L'API Swift garantit un ordre stable, pas l'égalité
  avec le flux de torch.
- **Condition négative** : `cond.apply(torch.zeros_like)` = **zéros avant** `cond_embedder` /
  `cond_embedder2` : la branche négative reçoit donc les biais des deux projections.
- **CFG** : `v = (1 + w)·v(cond) − w·v(neg)`, w = 3 ; `batch_cfg` (lot de 2) n'est qu'une
  optimisation GPU, même formule.
- **Pas d'Euler** : `x ← x − v·(t − t_prev)`, sur les deux champs (`latent`, `camera`).
- **Caméra** : sortie du même débruitage (le jeton caméra est débruité avec le latent).
- **Décodage** : `decode(latent, num_gaussians)` ; l'octree descend jusqu'à `max_voxel_level` = 8
  (256³ cellules), 8 forwards du décodeur octree, puis **un** forward du décodeur gaussien sur
  tous les ancrages (auto-attention sur `num_gaussians/32` jetons).
- **Modes** : `synthetic` (marge 1,2) / `real` (1,7) ne changent que le recadrage.
