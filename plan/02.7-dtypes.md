## 2.7 Ordre des dtypes (à respecter pour la parité)

| Élément | Référence (GPU) | Swift `16bit-*` |
|---|---|---|
| Linear des blocs du débruiteur et des décodeurs | fp16 (`convert_module_to_f16`) | fp16 |
| Embeddings (input, cond, pos, t, cam), adaLN, `out_layer`, `cam_out_layer` | fp32 | fp32 |
| RePo (norm, gate/content/final maps, angles) | fp32 | fp32 |
| `LayerNorm32`, `MultiHeadRMSNorm` | calcul fp32, sortie au dtype d'entrée | idem |
| Rotation RoPE | fp32, cast au dtype de q/k | idem |
| État `h` entre blocs | fp16 | fp16 |
| État ODE (`latent`, `camera`) | fp32 (bruit `randn` fp32, vitesse sortie fp32) | fp32 |
| DINOv3 | bf16 (option fp32) | bf16 |
| VAE FLUX.2 (encodeur) | bf16, poids F32 castés au chargement | bf16 |
| BiRefNet | fp16 | fp16 |
| Systématique, ancrages | fp32 (CPU en Swift) | Float |

LayerNorm : eps 1e-6 dans les blocs, 1e-5 ailleurs (RePo, `F.layer_norm` sans paramètres, DINOv3) — `plan/02.2`.

Règles : jamais de constante fp32 qui promeut un état fp16 (pattern MLX-002) ; le `computeDType`
d'un Linear quantifié est explicite (jamais `weight.dtype`, piège YuE2 n° 10).
