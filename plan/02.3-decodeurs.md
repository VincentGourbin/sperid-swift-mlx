## 2.3 Décodeurs (`models/decoder.py`)

### Plongement de position v2 (`PcdAbsolutePositionEmbedderv2`, les deux décodeurs)
`freq_dim` = 1024/3/2 = 170, `freqs = 2^linspace(0, 10, 170)`, angle `x·f·π` (**π, pas 2π** —
contrairement au v1 du débruiteur), sortie `[sin(170), cos(170)]` par axe → 1020, zéro-padding à 1024.

### Décodeur octree `OctreeProbabilityFixedlenDecoder` (4 blocs, 50,8 M, 60 tenseurs)
- Entrée : centres de cellules [B,L,3] ∈ [0,1] ; `h = in_proj(x) + pos_v2(x)` puis `input_layer`.
- Niveau : `l_embedder` = sinusoïdal (`max_period` **1024**, `two_pi` vrai, cos puis sin) appliqué
  à **la résolution `1 << l`** (2, 4, …, 256), pas à l'indice l ; `adaLN_modulation` → 6×1024.
- Blocs `ModulatedTransformerCrossOnlyBlock` : pas d'auto-attention ; `norm1` (sans affine) →
  modulation → cross-attention vers le latent [B,8192,16] (`to_q`, `to_kv` 16 → 2048, RMSNorm
  multi-têtes q et k) → gate ; `norm2` → modulation → MLP → gate. **Pas de `shift_table`** ici.
- Sortie : `out_proj(layer_norm(out))` → 8 logits, softmax.
- Descente (`sample`, CPU sauf le forward) : niveau 1 à 8 ; parents `(coord + 0.5)/2^(l−1)` ;
  enfants `coord·2 + offset`, offsets dans l'ordre **x le plus rapide** :
  index = i + 2j + 4k ; `systematic_sample` répartit le compte de chaque parent ; on ne garde que
  les enfants non vides, compactés **dans l'ordre** (cumsum) ; à la fin chaque point est placé
  uniformément dans sa feuille : `(coord + U[0,1)³)/256`. Fait en Swift : `Decoding/SystematicSampler.swift` (T-1.0).
- Nombre de parents au niveau l ≤ min(8^(l−1), num_points) : le dernier forward voit au plus
  `num_points` cellules (8192 à 262 144 Gaussiennes).

### Décodeur gaussien `GaussianFixedlenDecoder` (16 blocs, 237,3 M, 328 tenseurs)
- `h = in_proj(points) + pos_v2(points)` puis `input_layer` ; blocs `TransformerCrossBlock` :
  `norm1` (sans affine) → **auto-attention** sur tous les ancrages ; `norm2` (**affine**) →
  cross-attention vers le latent ; `norm3` (sans affine) → MLP.
- Sortie `out_proj(layer_norm)` → 480 = 32 × 15, découpée **par attribut** puis par Gaussienne :
  `_xyz` 96, `_features_dc` 96, `_scaling` 96, `_rotation` 128, `_opacity` 32, `_offset_scale` 32 ;
  chaque tranche se lit [B, L, 32, dim].
- `to_representation` :
  `offset_scale = softplus(raw_os + base_offset_scale)` ;
  `offset = tanh(raw_xyz·lr_xyz + points_offset_perturbation[32,3]) · 0.5 · perturbe_size(1.5) · offset_scale` ;
  position brute = `offset + ancrage` ; autres attributs `raw · lr` (**rotation × 0,1**) ; puis
  activations de `Gaussian` (`Output/GaussianCloud.activate`, T-1.0).
- `points_offset_perturbation` et `base_offset_scale` sont **stockés dans les poids** (buffers).
