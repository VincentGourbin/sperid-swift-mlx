## 2.2 Débruiteur `LatentSeqMMFlowModel` (`models/dit.py`, `models/layers.py`)

Config : `q_token_length` 8192, `in_channels` 16, `cam_channels` 5, `model_channels` 1024,
`cond_channels` 1280, `cond2_channels` 128, 24 blocs joints + 2 + 2 raffineurs, 16 têtes × 64.
370,6 M paramètres, stockés **F32** (560 tenseurs).

### Forward
1. `h_x = input_layer(z)` → fp16 ; `h_cond = cond_embedder(f1) + cond_embedder2(f2)` → fp16.
2. `t_emb = t_embedder(1000·t)` (sinusoïdal 256, **cos puis sin**, `max_period` 10 000, MLP
   Linear-SiLU-Linear) ; `t_mod = adaLN_modulation(t_emb)` (SiLU, Linear 1024 → 6144) → fp16.
   Un seul `t_mod` partagé par tous les blocs modulés ; chaque bloc y ajoute sa `shift_table` [1,6144].
3. `h_x += pos_embedder(pos_pe)` : `pos_pe` [1,8192,3] = Sobol brouillé **stocké dans les poids** ;
   `PcdAbsolutePositionEmbedder` : `freq_dim` = 1024/3/2 = 170 fréquences
   `2^[0..15] ++ 2^(arange(154)/154·16)`, angle `x·f·2π`, `[sin, cos]` par axe puis **zéro-padding**
   de 1020 à 1024.
4. `noise_refiner` (2 blocs modulés) sur `h_x` ; `context_refiner` (2 blocs **non modulés**, LayerNorm
   affines) sur `h_cond` ; `cam_refiner` = MLP 5 → 1024 → 1024 (GELU tanh).
5. `h = cat([h_x, h_cond, h_cam])` — 8192 + 4101 + 1 = **12 294 jetons** — puis 24 blocs.
6. Sorties : `layer_norm` sans paramètres (fp32), `(1 + scale)·h + shift` avec
   `shift, scale = (shift_table [1,2,1024] + t_emb)` (le `t_emb` brut, pas `t_mod`), puis
   `out_layer` (1024 → 16) et `cam_out_layer` (1024 → 5).

### `UnifiedTransformerBlock`
- `norm1`/`norm2` = `LayerNorm32` (calcul fp32, eps 1e-6, **sans affine** si modulé).
- Modulé : `shift_msa, scale_msa, gate_msa, shift_mlp, scale_mlp, gate_mlp = (t_mod + shift_table).chunk(6)`.
- Attention `RopeMultiHeadAttention` : `qkv` → [B,L,3,16,64] ; **RoPE appliquée à q et k AVANT
  `q_norm`/`k_norm`** (piège 1) ; `MultiHeadRMSNorm` = `normalize(x.float(), dim=-1) · gamma[16,64]
  · √64` ; SDPA sans masque, échelle par défaut 1/√64 ; `out`.
- MLP : Linear 1024 → 4096, GELU **tanh**, Linear 4096 → 1024.

### RoPE apprise `RePo3DRotaryEmbedding` (une par bloc, calculée depuis l'entrée du bloc)
- `h = LayerNorm32(x)` (affine) ; `out = final_map(SiLU(gate_map(h)) · content_map(h))`
  (1024 → 128 → 48, sans biais) → `delta_pos` [B,L,16,3].
- Par axe a ∈ {0,1,2} : `ang_a = delta_pos[..., a] · freqs_a · π` ; `freqs` appris de tailles
  **10, 10, 12** (head_dim 64 = 20 + 20 + 24, `d//2` fréquences par axe).
  `clamp_mul(x, f) = x·tanh(f) + x·(f − tanh(f))` vaut **x·f** en inférence (le `detach` ne
  change que le gradient).
- `ang = cat(ang_0, ang_1, ang_2)` [B,L,16,32] ; rotation **par paires entrelacées**
  `(x[2i], x[2i+1])` : `[x0·cos − x1·sin, x0·sin + x1·cos]` en fp32 puis cast — c'est
  `traditional: true` de MLX, l'inverse de YuE2 (piège 2). La rotation dépend de la **tête**.

### Précision (référence GPU)
Linear des blocs (`blocks`, `noise_refiner`, `context_refiner`) en **fp16** ; embeddings,
`adaLN`, RePo, normes, sorties en **fp32**. `h` circule en fp16 entre blocs.
