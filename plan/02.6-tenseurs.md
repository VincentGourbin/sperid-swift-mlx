### Conventions de nommage → MLXNN
- Les Linear de la référence sont des `nn.Sequential` : `mlp.mlp.0` / `mlp.mlp.2`,
  `t_embedder.mlp.0` / `.2`, `adaLN_modulation.1` (index 0 = SiLU) — le module Swift garde ces
  index (`@ModuleInfo(key: "0")`) pour charger sans table de renommage.
- `MultiHeadRMSNorm.gamma` [16,64] : nom `gamma`, pas `weight`.
- Conv (BiRefNet, VAE) : layout PyTorch `[out, in, kh, kw]` → MLX `[out, kh, kw, in]`
  (transposition au chargement, tenseur par tenseur, piège 8).
- Clés `num_batches_tracked` et `relative_position_index` : ignorées (le second est recalculé
  ou lu comme entier, pas comme paramètre).
- DINOv3 : les clés Comfy suivent le format transformers (`layer.N.attention.q_proj`) ; celles du
  dépôt officiel (gated, non relu) sont **à vérifier** en T-3.1 avant de supposer l'identité.
- VAE FLUX.2 : clés Comfy et `FLUX.2-small-decoder/full_encoder_small_decoder.safetensors` (local)
  identiques sur les 111 clés `encoder.*`/`quant_conv.*`/`bn.*` ; égalité des **valeurs** à
  vérifier (SHA par tenseur) en T-3.3. Le dépôt `FLUX.2-dev/vae` est au format diffusers (à relire).
